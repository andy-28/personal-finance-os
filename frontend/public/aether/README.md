# Aether Public Assets

This directory holds original Coin Engine visual assets only.

Do not add unlicensed game assets, bank artwork, card artwork, logos, sprites, sounds, or screenshots.

Directory map:

- `branding/`: app-owned branding assets.
- `icons/system/`: 16-32px semantic system icons.
- `icons/resources/`: 24-48px resource icons.
- `objects/cards/`: card object art and card emblems.
- `frames/`: frame and ornament assets.
- `effects/`: restrained effects and dividers.

All new assets should be wired through `frontend/lib/aether/asset-registry.ts`.
